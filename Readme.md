📡 LoRa Sniffer (Heltec WiFi LoRa 32 V3)

Автономный сниффер пакетов LoRa на базе платы Heltec WiFi LoRa 32 V3. Устройство поднимает собственную Wi-Fi сеть и веб-интерфейс, позволяя перехватывать, отображать и записывать LoRa-трафик прямо с телефона или компьютера без необходимости подключения к ПК.

✨ Возможности

Перехват LoRa-пакетов на чипе SX1262 с настройкой всех ключевых параметров (Частота, BW, SF, CR, Sync Word, Preamble, CRC, IQ).
Режим сканирования (Scan Mode): автоматический перебор популярных пресетов (LoRaWAN, Meshtastic, MeshCore, приватные сети) для поиска неизвестных передатчиков.
Wi-Fi Точка Доступа: разворачивает сеть LoRaSniffer с IP-адресом 192.168.0.1 и DHCP-сервером.
Веб-интерфейс:

Отображение последних пакетов в реальном времени (WebSocket) в формате ASCII и HEX.
Настройка радиоэфира.
Управление записью дампа.
Запись дампа: сохранение принятых пакетов в бинарный файл на внутренней флеш-памяти (LittleFS) с возможностью скачивания через браузер.
OLED-дисплей: отображение IP-адреса, количества принятых пакетов, текущих параметров и статуса записи.
Управление кнопкой: короткое нажатие на кнопку USER (GPIO0) на плате запускает и останавливает режим сканирования.
Энергонезависимая память (NVS): все настройки радио сохраняются после перезагрузки платы.
🛠 Аппаратное обеспечение

Плата Heltec WiFi LoRa 32 V3 (ESP32-S3 + SX1262 + SSD1306 OLED).
Антенна, соответствующая диапазону частот (868 МГц для EU/РФ, 915 МГц для US, 433 МГц для Азии).
USB-кабель для прошивки и питания.
💻 Сборка и прошивка

Проект собирается с помощью PlatformIO (рекомендуется использовать VS Code с расширением PlatformIO IDE).

Клонируйте репозиторий:

bash
git clone https://github.com/vodolazov2008/heltek-sniffer.git
cd heltek-sniffer
Откройте папку проекта в VS Code.
Подключите плату к компьютеру по USB.
Загрузите файловую систему (HTML-интерфейс):

bash
pio run --target uploadfs
Скомпилируйте и прошейте микроконтроллер:

bash
pio run --target upload
Примечание для macOS: Если порт не определяется или не загружается прошивка, установите драйвер CP210x от Silicon Labs. В редких случаях может потребоваться перевод платы в режим Bootloader (зажать BOOT, нажать RST, отпустить BOOT).
🚀 Использование

Включите плату (подайте питание через USB или PowerBank).
На OLED-экране появится IP-адрес и статус. Дисплей включается автоматически (в коде реализована подача питания через пин Vext).
Подключитесь к Wi-Fi сети:

SSID: LoRaSniffer
Пароль: sniffer123
Откройте в браузере (телефон или ПК): http://192.168.0.1
🎯 Поиск неизвестного передатчика (Режим сканирования)

Если вы не знаете параметров эфира (например, для датчика или метеостанции), используйте Режим сканирования:

Нажмите «Начать сканирование» в веб-интерфейсе (или коротко нажмите кнопку USER на плате).
Устройство начнет перебирать пресеты (каждые 15 секунд).
Как только на каком-то пресете будут пойманы пакеты, он подсветится желтым в таблице, а на OLED появится имя пресета.
Остановите сканирование и вручную введите найденные параметры в форму для дальнейшей работы.
Совет: Промышленные датчики (например, LoRaWAN-анемометры) передают данные редко (раз в 1-10 минут). В коде можно увеличить время удержания одного пресета: #define PRESET_DURATION_MS 15000 (15 секунд) на большее значение.
💾 Формат дампа

При нажатии «Начать запись» данные пишутся в файл /dump.loradump на внутренней памяти. Это бинарный файл. Структура каждой записи (заголовок 13 байт + данные):

c
struct PacketRecord {
    uint32_t timeMs;   // Время приема (millis)
    float    rssi;     // Уровень сигнала
    float    snr;      // Отношение сигнал/шум
    uint8_t  len;      // Длина пакета в байтах
    uint8_t  data[len]; // Сырые данные пакета
};
Пример Python-скрипта для парсинга дампа:

python
import struct

def parse_dump(filename):
    with open(filename, "rb") as f:
        while True:
            header = f.read(13)
            if not header:
                break
            time_ms, rssi, snr, length = struct.unpack("<IffB", header)
            payload = f.read(length)
            print(f"[{time_ms} ms] RSSI: {rssi:.1f}, SNR: {snr:.1f}, Data: {payload.hex().upper()}")

# Использование:
# parse_dump("dump.loradump")
⚠️ Известные нюансы

Питание OLED: На платах Heltec V3 дисплей не работает без подачи низкого уровня (LOW) на пин GPIO36 (Vext). В коде это уже учтено.
Кнопка USER: Завязана на GPIO0. Это strapping-пин, поэтому не удерживайте кнопку при включении платы, иначе она войдет в режим загрузчика.
Serial Monitor: Если вы не видите логов в мониторе порта, убедитесь, что слушаете UART (/dev/cu.SLAB_USBtoUART), а не Native USB, либо проверьте настройки флагов в platformio.ini.
